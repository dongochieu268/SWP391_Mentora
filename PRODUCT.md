# Product

## Register

product

## Users

Mentora serves three role-based user groups: admins preparing academic data and accounts, lecturers building classes and learning paths, and students joining classes to study through roadmap nodes, assessments, and Q&A.

## Product Purpose

Mentora is a Spring MVC learning management application for SWP391 coursework. It helps lecturers design course structure, manage classroom activity, maintain question banks, and guide students through learning progress. Success means each role can complete its teaching or learning workflow without needing off-screen explanation.

## Brand Personality

Clear, academic, practical. The interface should feel familiar and dependable, with restrained product styling that supports repeated classroom operations.

## Anti-references

Do not make lecturer/admin tools feel like a marketing landing page. Avoid decorative dashboards, oversized hero sections, invented controls, saturated inactive states, or UI copy that explains obvious mechanics instead of helping users act.

## Design Principles

1. Keep role workflows obvious: every screen should make the next teaching or learning action easy to find.
2. Prefer dense but readable product layouts for repeated use.
3. Reuse existing Bootstrap, Tabler icon, card, table, alert, and modal patterns unless a workflow clearly needs a different structure.
4. Use Vietnamese labels consistently with the existing app copy.
5. Treat academic records and assessment data as durable, auditable information.

## Accessibility & Inclusion

Use semantic forms, tables, buttons, labels, and focusable controls. Preserve contrast for body text and state messages, keep workflows keyboard-operable, and avoid decorative motion that can distract from classroom tasks.
