Bài học
Mục tiêu của bài học là giúp sinh viên hiểu cách khai báo entity, repository và xử lý dữ liệu từ SQL Server trong ứng dụng Spring Boot.
Video bài giảng
Ghi chú trọng tâm

Repository giúp tách truy vấn dữ liệu khỏi controller. Sinh viên cần cấu hình connection string, entity mapping và kiểm tra dữ liệu trả về trước khi chuyển sang phần service.

  • Khai báo entity bằng `@Entity`, `@Table`, `@Id`.
  • Tạo repository kế thừa `JpaRepository`.
  • Dùng service để kiểm soát nghiệp vụ trước khi render view.
